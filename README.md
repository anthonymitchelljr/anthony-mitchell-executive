# Anthony Mitchell Executive Site

A clean, responsive GitHub Pages website for Anthony L. Mitchell Jr.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example:
   `anthony-mitchell-executive`
2. Upload all files and folders from this package to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Save. GitHub will provide the live website address after deployment.
